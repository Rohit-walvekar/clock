# QR Code Generator

A simple and responsive **QR Code Generator** built using **HTML, CSS, and JavaScript**. This application allows users to instantly generate QR codes for any text or website URL. It provides a clean interface and generates a scannable QR code within seconds.

I built this project to improve my understanding of working with APIs, JavaScript DOM manipulation, and creating responsive user interfaces.

---

## Features

- Generate QR codes instantly
- Supports both text and website URLs
- Clean and modern user interface
- Smooth animations while generating QR codes
- Responsive design for desktop and mobile devices
- Easy to use with a single click

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- QR Code API

## ▶️ Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/Rohit-walvekar/qr-code-generator.git
```

### 2. Navigate to the project folder

```bash
cd qr-code-generator
```

### 3. Open the project

Simply open the **index.html** file in your browser.

Or, if you're using **VS Code**, install the **Live Server** extension and click **Go Live**.
