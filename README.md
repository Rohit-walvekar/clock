# JavaScript Clock

A simple and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**. The application displays the current time and updates automatically every second, providing a smooth and accurate real-time clock experience.

I created this project to strengthen my understanding of JavaScript, DOM manipulation, and working with time-based functions.

---

## Features

- Displays the current time in real time
- Automatically updates every second
- Clean and responsive user interface
- Built using pure JavaScript without any frameworks
- Lightweight and easy to use

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/Rohit-walvekar/javascript-clock.git
```

### 2. Navigate to the project folder

```bash
cd javascript-clock
```

### 3. Open the project

Simply open the **index.html** file in your browser.

Or, if you're using **VS Code**, install the **Live Server** extension and click **Go Live** to run the project.
